🎯 什么是 A-MEM？

A-MEM (Agentic Memory) 是一种为 LLM 代理设计的智能记忆系统。它借鉴了 Zettelkasten 笔记方法，让 AI 能够动态组织、链接和进化其记忆。

# 添加新记忆的代码流程 def add_note(content: str) -> str: # 1. 创建记忆笔记，触发 LLM 分析 note = MemoryNote( content=content, llm_controller=self.llm_controller # 自动分析 ) # 2. 处理记忆进化 evo_label, note = self.process_memory(note) # 3. 存储记忆 self.memories[note.id] = note # 4. 添加到检索索引 self.retriever.add_documents([ "content:" + note.content + " context:" + note.context + " keywords: " + ", ".join(note.keywords) ]) return note.id

🧬 记忆进化机制

A-MEM 的核心创新在于记忆的自主进化。系统会分析新记忆与现有记忆的关系，决定如何更新记忆网络。

🤔 进化决策

分析新记忆与最近邻记忆的关系

🚫 NO_EVOLUTION

记忆独立存在，无需建立关联

🔗 STRENGTHEN

加强新记忆与邻居的链接

📝 UPDATE_NEIGHBOR

更新邻居记忆的上下文

🔄 STRENGTHEN_AND_UPDATE

同时加强链接和更新邻居

👆 点击上方选项查看详细说明

📊 进化流程

Step 1: 检索邻居

使用语义检索找到与新记忆最相似的 K 个邻居记忆

Step 2: 进化决策 (LLM Call #1)

将新记忆和邻居信息发送给 LLM，判断需要哪种进化操作

Step 3: 获取详细信息 (LLM Call #2)

如果需要 STRENGTHEN，获取具体要建立哪些链接

Step 4: 更新邻居 (LLM Call #3)

如果需要 UPDATE_NEIGHBOR，获取邻居记忆的更新内容

Step 5: 应用更新

将决策结果应用到记忆网络中

💻 检索代码

class SimpleEmbeddingRetriever: def search(self, query: str, k: int = 5) -> List[int]: # 1. 将查询转换为向量 query_embedding = self.model.encode([query])[0] # 2. 计算与所有记忆的余弦相似度 similarities = cosine_similarity( [query_embedding], self.embeddings )[0] # 3. 返回最相似的 k 个索引 top_k_indices = np.argsort(similarities)[-k:][::-1] return top_k_indices.tolist()
